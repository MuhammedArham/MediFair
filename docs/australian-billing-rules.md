# Australian cost review rules — fictional demo

Reviewed **11 October 2026 (Australia/Sydney)**. All rules produce questions for review, not legal conclusions, clinical advice, coverage decisions or guaranteed savings. The executable rules are in `src/lib/opportunities/engine.ts`; source metadata is in `src/lib/opportunities/sources.ts`. Every finding stores its rule, official URL, source-linked evidence, missing inputs, responsible party, suggested questions, confidence, verification state, status and optional documented amount to clarify. No LLM or external service is needed. Findings are sorted by source evidence, actionability, documented discrepancies, a known contact and possible cost relevance. Priority is an ordering score, **not** a likelihood of success.

The MBS homepage and downloads are **context only** and support none of the fee-negotiation triggers. ## Processing and safety

`loadReviewInput` selects the latest source-dated fictional quote for each practice and structured text-PDF results already attached to the case. The pure engine rechecks scope through the existing bill comparator. Stable hashed IDs identify rules and source records, and a unique database key prevents duplicate saved drafts. The patient can disclose hardship, request a discretionary fee enquiry, document an unresolved fictional complaint, resolve it, and generate/edit an unsent request. Every server action requires the localhost development demo gate and validates inputs. No OpenAI or Resend call occurs. No request is approved or sent by this feature. Uploaded documents remain under the private document workflow.
